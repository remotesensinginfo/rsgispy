rsgispy.elevation
=================

The :mod:`rsgispy.elevation` subpackage provides terrain and digital elevation model (DEM) analysis modules using ``rasterio`` and ``numpy``: ``terrain``, ``illumination``, ``filtering``, ``fusion``, and ``roughness``.
