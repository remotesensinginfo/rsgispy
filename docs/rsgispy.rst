rsgispy Base Module
===================

The top-level :mod:`rsgispy` module defines image data type constants, the base :class:`~rsgispy.RSGISPyException` class, and helper functions to convert between RSGIS data type constants, ``rasterio``/GDAL data type strings, and ``numpy`` dtypes.

Data Type Constants
-------------------

* ``rsgispy.TYPE_UNDEFINED = 0``
* ``rsgispy.TYPE_8INT = 1``
* ``rsgispy.TYPE_16INT = 2``
* ``rsgispy.TYPE_32INT = 3``
* ``rsgispy.TYPE_64INT = 4``
* ``rsgispy.TYPE_8UINT = 5``
* ``rsgispy.TYPE_16UINT = 6``
* ``rsgispy.TYPE_32UINT = 7``
* ``rsgispy.TYPE_64UINT = 8``
* ``rsgispy.TYPE_32FLOAT = 9``
* ``rsgispy.TYPE_64FLOAT = 10``
