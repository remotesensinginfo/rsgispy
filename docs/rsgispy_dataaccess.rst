rsgispy.dataaccess
==================

The :mod:`rsgispy.dataaccess` subpackage provides clients for searching and downloading datasets from Copernicus Data Space Ecosystem (OData), NASA CMR, OpenStreetMap, Planet Data/Orders API, and USGS M2M.
